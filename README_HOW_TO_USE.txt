HOW TO RUN ON YOUR DEVICE (PHONE / TABLET / PC / LAPTOP):
--------------------------------------------------------------------------------
1. STANDALONE OFFLINE USE (NO INTERNET NEEDED):
   - Simply double-click "VeriTol_Prototype.html" to open in Google Chrome,
     Microsoft Edge, Mozilla Firefox, or Apple Safari.
   - On a mobile phone (Android / iPhone):
     Transfer "VeriTol_Prototype.html" to your phone via USB, WhatsApp, Telegram,
     Drive, or AirDrop. Tap the file and select Chrome, Edge, or Safari to open.
   - All 100 Legal Metrology model approvals, high-resolution equipment photos,
     deterministic MPE calculation engine, QR code generator, and offline storage
     are 100% EMBEDDED inside this single file.

2. RUNNING WITH LIVE BACKEND (OPTIONAL DEVELOPER MODE):
   - Open PowerShell or Terminal in this folder.
   - Run: python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
   - Open http://127.0.0.1:8000/ on your computer.
   - On mobile connected to the same Wi-Fi, open http://192.168.1.3:8000/

PACKAGE CONTENTS:
--------------------------------------------------------------------------------
- VeriTol_Prototype.html: Standalone full single-file platform.
- VeriTol_100_Model_Approval_Records_FINAL.xlsx: 100 official model approval records.
- images/: High-resolution metrological hardware photographs for all 10 instrument categories.
- README_HOW_TO_USE.txt: This instruction guide.
